## 診断観点（5レイヤー）

以下の5レイヤーで診断し、最後に総合所見を述べてください。**先に観点ごとの診断を済ませてから、最後に統合してください。**

### レイヤー1. シリーズアーク全体

連載ドラマ全体を 1 つの物語として見たとき、起承転結のどこに重みがあるか。具体的には:

- **第1話のフック**: 視聴を継続させる引きが効いているか
- **中盤の起伏**: 中だるみの兆候はないか / どの話で勢いが変わるか
- **終盤の盛り上がり**: 最終話に向けたエネルギー集中は機能しているか
- **最終話の決着**: 提示された問いに答えているか / 余韻があるか

### レイヤー2. 各話の機能

各話が連載において担う「機能」を1〜3行で要約せよ。次のいずれかに分類できるはず:

- **情報開示**: 新事実が明かされる
- **関係変化**: 人間関係の力学が動く
- **状況変化**: 物理的・社会的状況が変わる
- **感情変化**: 主要キャラの内面が変わる

機能が薄い話 / 重複する機能の話があれば指摘する。

### レイヤー3. 感情アーク6種判定

Reagan & Mitchell (2016) の6つの基本物語アークのうち、本作のシリーズ全体がどれに最も近いかを判定し、根拠を述べる。

1. **Rags to Riches** — 上昇のみ
2. **Riches to Rags** — 下降のみ
3. **Man in a Hole** — 下降→上昇
4. **Icarus** — 上昇→下降
5. **Cinderella** — 上昇→下降→上昇
6. **Oedipus** — 下降→上昇→下降

複数アークが入れ子になっている場合は、主要キャラごとにアークを分けて判定してよい。

### レイヤー4. 主要キャラの動機線

主要登場人物（3〜5名）について、以下を表形式で記述:

| キャラ名 | 第1話時点の動機 | 終盤の動機 | 動機の変化 | 動機の納得感（5段階） |
|---|---|---|---|---:|

「動機の納得感」が 3 以下のキャラがいれば、どの話のどのシーンで動機線が破綻しているかを指摘する。

### レイヤー5. テーマの貫徹度

作品が掲げる（または匂わせる）テーマが、最終話まで一貫して描かれているか。次の3つを記述:

- **顕在的テーマ**（作品が明示的に語っているもの）
- **潜在的テーマ**（行動や対比で語られているもの）
- **テーマと結末の整合性**

## 診断時の心がけ

- **強みを先に、十分に**: 改善点を語る前に、作品の良さを具体的シーン名で 3 点以上挙げる。創作は精神的に消耗する作業。書き手が次の一歩を踏み出すための土台作りを最優先にする
- **シーン名を引用する**: 「第◯話の〇シーン名 のこの部分」と具体的に指す。抽象的な批評は混乱と落胆を招く
- **「方向性」として表現する**: 「ここがダメ」「弱い」「破綻している」のような断定的・否定的な言い回しを避ける。「ここがもう一段強くなる余地」「この魅力をさらに引き立てるなら」と、**改善の方向**として伝える
- **問題指摘 → 必ず対応策 3 案**: 「ここが気になる」で終わらせない。各案にトレードオフ（何を得て何を失うか）と工数感を併記する。最終判断は書き手に委ねる前提で、選択肢を提示する役割に徹する
- **対応策の幅を出す**: 同じレイヤーの中で似た案を3つ並べない。A案=保守的最小修正 / B案=中規模リライト / C案=構造踏み込み のように**踏み込み度合いを変える**ことで、書き手の状況・スケジュール・気力に応じた選択を可能にする
- **観点を混ぜない**: レイヤー1〜5 を独立して書ききってから、最後に統合する
- **作家性を尊重**: 安易に「分かりやすさ優先」「ハッピーエンド推奨」と決めつけない。作品が志向するトーンと作家のスタイルを尊重する
- **創作への敬意**: 診断は「この作品を作った時間と労力」への敬意を持って書く。**書き手のメンタル**と**創作意欲**を守ることを最優先する。指摘の鋭さよりも、**書き手が「次に書きたい」と思える助言**であることを目指す
- **スコアの扱い**: 数値スコアは現時点での到達度を示す指標であり、書き手の能力評価ではない。スコアを出すときは必ず「ここから伸びる余地」をセットで示す
