タイトル: 脚本の構造診断ツールを OSS で公開しました — script-review-mcp
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━


連載ドラマ・映画・小説の脚本（.docx）を AI が構造診断してくれる MCP サーバーを、PEARL株式会社 / Light Rewrite Studio として MITライセンスで OSS 公開しました。

GitHub: https://github.com/yama-kiyo/script-review-mcp

Claude Code / Claude Desktop / その他 MCP クライアント上で「この脚本を診断して: ◯◯.docx」と話しかけるだけで、5レイヤーの構造診断レポートが返ってきます。


■ なぜ作ったか

ホン直しの現場で、自分の書いた脚本に対してセカンドオピニオンを欲しいと思うことがよくあります。

ただ、信頼できる相手に見てもらうのは時間も気を遣う。コミュニティでフィードバックをもらうと玉石混交。AIに見せても「ここがダメ」とだけ言われて凹むパターンもあります。

そこで、自分のホン直しワークフローのために作っていた診断プロンプトを、OSS フレームワークとして整えて公開しました。誰でも自分の作風に合わせてカスタマイズして使えます。


■ 何ができるか

入力: .docx の脚本またはプロット
出力: マークダウン形式の構造診断レポート

診断観点は 5 レイヤー。

1. シリーズアーク全体（第1話のフック / 中盤の起伏 / 終盤の盛り上がり / 最終話の決着）
2. 各話の機能（情報開示 / 関係変化 / 状況変化 / 感情変化のどれを担っているか）
3. 感情アーク 6 種判定（Reagan & Mitchell 2016: Rags to Riches / Man in a Hole / Icarus / Cinderella / Oedipus / Riches to Rags）
4. 主要キャラの動機線（始点と終点の変化、納得感5段階）
5. テーマの貫徹度（顕在テーマ / 潜在テーマ / 結末との整合性）

連載 30 話くらいなら全話通しで 3〜5 分で診断が出ます。


■ 設計で一番こだわった点 — 「批評ではなく助言者であること」

似たツールはいくつかありますが、たいてい「ここがダメ」「弱い」「破綻している」と断定的に指摘してきて、書き手のメンタルが削られる問題があります。

このツールは設計思想として:

・改善点を語る前に、強みを具体的シーン名で 3 点以上挙げる
・「ダメ」「弱い」「破綻」のような断定を避け、「もう一段強くなる余地」「この魅力をさらに引き立てるなら」と方向性として伝える
・問題指摘で終わらせず、対応策を必ず 3 案提示する
・3 案は踏み込み度合いを変える: A案=保守的最小修正 / B案=中規模リライト / C案=構造踏み込み
・各案のトレードオフ（何を得て何を失うか）と工数感を併記する
・最終判断は常に書き手に委ねる（AIは選択肢提示者）

「書き手が次に書きたいと思える助言」を出すことを最優先にしています。創作は精神的に消耗する作業なので、書き手のモチベーションを守ることが診断品質の一部だと考えています。


■ 注意点（使う前に）

1. AI 診断は完璧ではありません。生成された改善提案は参考意見として扱い、最終判断は書き手・脚本家・監督が行ってください。

2. 入力の .docx には「第１話」「第2話」のようなエピソード境界の行があると、各話別に解析されます。境界がない場合は全文を1話として扱います。

3. 診断観点は src/script_review_mcp/prompts/script_all.md がテンプレート。コピーして script_all.local.md を作ると、それが自動的に優先されます（公開対象外、自分の作風に合わせて自由にカスタマイズ可能）。

4. クライアント機密の脚本をテストに使う場合は *.private.docx 形式で命名すれば .gitignore で除外されます。


■ インストール（5分程度）

Python 3.11 以上が必要です。

git clone https://github.com/yama-kiyo/script-review-mcp.git
cd script-review-mcp
python3 -m venv .venv
source .venv/bin/activate
pip install -e .

Claude Code に登録:

claude mcp add script-review --scope user -- "$(pwd)/.venv/bin/python" -m script_review_mcp

確認:

claude mcp list

これで「この脚本を診断して: パス」と話しかけるだけで使えます。


■ 想定ユーザー

・連載ドラマや長編脚本を書いていて、全体構造のセカンドオピニオンが欲しい脚本家・監督
・AI ビデオ制作で生成された脚本の品質チェックを仕組み化したい制作会社
・物語構造の理論（三幕構成 / Save the Cat / 6感情アーク）を自分の作品に当てはめて学びたい人
・自分の作風に合わせた診断観点をカスタマイズしたい上級ユーザー


■ ロードマップ

Phase 1（公開済み）: 連載脚本の全話通し構造診断
Phase 2: 1話単位の三幕構成診断
Phase 3: プロット用診断（地の文ベース）
Phase 4: キャラ整合性 / セリフ品質 / IP安全性チェック
